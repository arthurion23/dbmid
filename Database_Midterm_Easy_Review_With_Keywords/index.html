SQL & ERD Practice — exam extensions

The uploaded Database Midterm photo asks about HAVING, LEFT JOIN and GROUP BY; the uploaded SampleMidterm asks for football-team ERD. These examples supplement the five lecture slides. They should not be treated as exact quotations from the lectures.

WHERE vs HAVING vs GROUP BY

WHERE filters rows before aggregation; GROUP BY groups rows; HAVING filters aggregated groups.

SELECT City, SUM(Sales) AS TotalSales
FROM Orders
GROUP BY City
HAVING SUM(Sales) > 10000;

لو عايز المدن اللي إجمالي مبيعاتها أكبر من 10000، بنستخدم HAVING بعد GROUP BY.

LEFT JOIN

SELECT s.Name, e.CourseID
FROM Students AS s
LEFT JOIN Enrollments AS e
  ON s.StudentID = e.StudentID;

Includes unmatched rows from the left table; right-side columns are NULL when no match exists.

بيرجع كل صفوف الجدول الأيسر حتى لو مفيش سجل مطابق في الجدول الأيمن.

Keys & constraints

CREATE TABLE Course (
  CourseID INT PRIMARY KEY,
  Title VARCHAR(100) NOT NULL
);
CREATE TABLE Enrollment (
  StudentID INT NOT NULL,
  CourseID INT NOT NULL,
  FOREIGN KEY (CourseID)
    REFERENCES Course(CourseID)
);

المفتاح الأساسي فريد وغير فارغ، والمفتاح الأجنبي يربط الجدولين بشرط سلامة المرجع.

ERD: football teams sample exam

Key entities: TEAM, PLAYER, MATCH, REFEREE, MATCH_PLAYER.

Relationships: one team has many players; a match has host and guest teams; MatchPlayer stores goals and cards; a match uses exactly three referees with main/assistant roles; substitution relates participants with a time.

عند حل ERD اكتب الكيانات ومفاتيحها أولًا، ثم العلاقات والكارديناليتي، ثم صفات العلاقات مثل الأهداف والكروت ووقت التبديل.
